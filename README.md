# AUTOQECFILL 1-Click QEC Form Filler

Tired of filling that QEC form manually and clicking through every field? AUTOQECFILL is a Chrome extension that fills all Air University QEC forms for you in one click.

## What it does

- Automates all Air University QEC forms (Teacher, Course, Online Learning).
- Applies a default grade to everything, with per-course/teacher exceptions.
- Runs quietly in the background so you can stay on the portal.

## How to use

1. Login to the [Air University QEC Portal](https://portals.au.edu.pk/qec/login.aspx).
2. Click the AUTOQECFILL extension button you pinned earlier.
3. Select the default grade you want to assign to all courses.
4. Click the Sync Portal button to load your current QEC data.
5. Add exceptions, if needed — for example, giving an A grade to Quranic Studies.
6. Click the Do the Thing button to start automation.
7. Watch as AUTOQECFILL fills default grades for all courses while applying your exception grades to the specified courses and teachers.
8. The extension will complete all three forms automatically, one by one.
9. A progress bar shows real-time progress during automation.
10. Once finished, click the View Report button to review all assigned grades.

## Notes

Make sure you are logged into the portal before starting automation.
